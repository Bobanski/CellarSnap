## Newly confirmed limitation: QC-13
A valid bearer-only request to `/api/grapes?q=nebbiolo&limit=8` returns **401 on both the candidate and pre-B05c live production**, while `/api/taste-survey` with the same token returns 200. The grape route uses only cookies; native callers send Authorization headers. Same-host Expo web can inherit cookies and hide this. [Sanitized HTTP evidence](../remediation/evidence/b05c-bearer-search.json), source reproduction and acceptance are in QC-13. This is an existing defect explicitly left for the next bounded authenticated-query slice, not a regression or a claim of working native autocomplete.
