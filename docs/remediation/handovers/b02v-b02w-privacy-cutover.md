- Private knowledge content and exact source fingerprints survive migration installation and activation. Later source updates invalidate stale knowledge. Null clears, 1/100 boundaries, invalid writes, CAS/no-op retry, grape rollback, insert-conflict and stale transactions are covered. Legacy partial-update receipts rehydrate owner ratings after mutation.
- Legacy Storage cutoff uses actual operation-aware restrictive policies. Metadata authorization is independent of direct Storage SELECT. All nine canonical reference columns are fenced against retired paths with a locked epoch; old repeatable-read writers abort. Avatar rekey and unique replacements are supported. Avatar replacement no longer deletes old keys before verified retirement.
- `retire` rehashes replacements, verifies protected application access and durable DB proof, deletes through Storage API, and resumes an uncertain delete by the same operation ID. `observe` records bounded two-region raw/transformed warmed-capability denials. Trusted operator observations do not prove universal CDN invalidation or erase previously downloaded bytes.
- Rating source tables must stay outside Realtime/logical publications because the AFTER trigger generates intermediate WAL tuples. Activation checks existing publications. Do not restore exposed legacy numbers as rollback.
