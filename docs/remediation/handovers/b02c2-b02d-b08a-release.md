No key rotation, bulk purge or original object rewrite.

Unchanged ordered selections issue zero grape writes, retaining link rows and avoiding overwriting concurrent grape-only changes. The selection remains visible and retry succeeds, but crash/concurrent explicit-edit recovery needs a transaction/idempotency slice. No historical grape-loss repair was attempted.
